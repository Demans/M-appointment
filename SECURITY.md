# Security and privacy policy

This repository is a portfolio-safe demonstration. It must remain independent
from any real appointment service or personal booking workflow.

## Never commit

- Production or private URLs
- API keys, bot tokens, chat IDs, cookies, or authentication headers
- Names, contact details, identity documents, booking answers, or form profiles
- Captured pages from a live service
- Runtime state, logs, screenshots, archives, caches, or generated build metadata
- Autofill or automatic booking functionality

Only synthetic fixtures are permitted. If a secret is committed, revoke it at
the provider immediately; removing the file from the latest commit is not enough.
